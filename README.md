# Analisis Ketersediaan Fasilitas Kesehatan di Jawa Barat Tahun 2024

**Data Wrangling | Exploratory Data Analysis | Python**

## Deskripsi Proyek
Proyek ini bertujuan untuk menganalisis ketersediaan fasilitas kesehatan dan rumah sakit berdasarkan jumlah penduduk di 27 kabupaten/kota Jawa Barat tahun 2024.

Analisis dilakukan melalui proses **data cleaning, transformation, integration, dan Exploratory Data Analysis (EDA)** menggunakan tiga dataset dari BPS, Open Data Jabar, dan Kaggle.

## Tools & Libraries
- **Python**
- **Pandas** – Data cleaning, transformation, dan integration
- **Matplotlib** – Visualisasi data
- **Jupyter Notebook** – Pengembangan dan dokumentasi analisis

## Tahapan Proyek
1. **Data Collection:** Mengumpulkan tiga dataset dari berbagai sumber.
2. **Data Cleaning:** Menangani missing values, menyamakan format, dan memperbaiki tipe data.
3. **Data Transformation:** Normalisasi nama wilayah dan agregasi data.
4. **Data Integration:** Menggabungkan dataset menggunakan `pd.merge()`.
5. **EDA:** Menganalisis distribusi penduduk dan ketersediaan fasilitas kesehatan.

## Hasil Analisis
- Menghasilkan dataset terintegrasi dari 27 kabupaten/kota.
- Mengidentifikasi ketimpangan ketersediaan rumah sakit terhadap jumlah penduduk.
- Menemukan bahwa Kabupaten Bogor dan Bandung memiliki estimasi kekurangan rumah sakit berdasarkan rasio analisis.
- Menyajikan visualisasi perbandingan jumlah penduduk dan fasilitas kesehatan.
